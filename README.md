# Asteriod-Hazadous-Predictions-using-machine-learning
Project Overview

This project aims to estimate the probability of potentially habitable exoplanets using Machine Learning techniques.

With the increasing amount of astronomical data generated by space missions such as Kepler and K2, machine learning provides an effective approach for analysing planetary characteristics and identifying exoplanets that may have conditions suitable for life.
Dataset

    Dataset: Habitable Worlds Catalogue (HWC)

    Number of records: 5,599 exoplanets

    Target: Binary habitability classification

    Data type: Planetary and stellar characteristics

Methodology

    Data collection and exploratory data analysis.

    Data preprocessing and missing-value imputation.

    Conversion of habitability labels into a binary target.

    Stratified train-test splitting to handle class imbalance.

    Model training using Random Forest Classifier.

    Model evaluation and feature importance analysis.

Machine Learning Model

Random Forest Classifier was used with the following parameters:

    n_estimators = 200

    max_depth = 10

    class_weight = balanced

    random_state = 42
